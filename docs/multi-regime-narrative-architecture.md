# Multi-Regime Long-Form Narrative Architecture Upgrade

Date: 2026-10-05. Decision: **PROVISIONAL**. Scope: Chinese Long-Form Architect Skill, its existing reference owners, prewriting/context/readiness surfaces, and maintenance qualification. Workbench UI, C#/Avalonia, runtime schemas, and Auditability Core implementation were outside this change.

## 1. Existing capability inventory

The pre-change inventory is preserved in [inventory.md](multi-regime-results/inventory.md). Existing support included Project Poetics' organizing-principle responsibility, salience and exclusions; subjective/relational change; social institutions; memory and duration; open-issue compatibility; scoped authority; fair-clue reader contracts; ten revision-preservation fixtures; and calibrated, blinded pointwise and swapped pairwise judging. Baseline Fast, Core, Integration (80 tests), and the ten-fixture oracle passed. Baseline evidence is retained rather than overwritten.

## 2. Actual gaps

Support was uneven rather than absent. Event-driven language in Time/Scene/Long Horizon could eclipse accumulation in memory, perception, self-understanding or relations. The Skill lacked a compact organizing vocabulary separated from mediation, explanation and temporal form. Social ascent/private loss, associative memory, atmospheric relations, metaphysical contestation and locally closed episodic cases lacked sufficient qualification fixtures. Revision preservation alone could not qualify planning or drafting. Writer capability selection previously boosted relevant entries but could still admit inactive entries when budget remained. Readiness needed explicit consequential draft dependencies without treating every artistic ambiguity as a blocker.

## 3. Architecture decision

Extend **Project Poetics as the existing organizing owner**, then compile choices into existing Narrative Strategy, Chapter Mission and Writer context. No new reference owner, NarrativeEngine artifact, runtime state stratum, named-work preset or exclusive narrative-mode enum was created. The audit found an existing owner for the semantic responsibility; a second owner would duplicate it. Consequently no ownership-freeze exception was needed. Evaluation extends the existing behavioral-oracle owner; the new qualification script is a maintenance orchestrator, not a literary engine.

Progression means irreversible change or meaningful accumulation in a project-authorized tracked state. This can be external options, hypotheses, social position, relation, self-model, memory organization, perception, object relation, interpretive plausibility, formal pattern or reader expectation. Deliberate stasis can justify duration without being falsely reported as change.

## 4. Organizing principles vocabulary

Diagnostic, composable families: causal/action; investigative/epistemic; social/strategic; relational; subjective/consciousness; memory/temporal; perceptual/atmospheric; obsessive/object-idea; metaphysical/interpretive; formal/polyphonic. These are not an exhaustive taxonomy. A project identifies dominant and supporting work, background dimensions and inactive capabilities. Scope may vary by volume, arc, chapter and scene. A dinner can perform social strategy, memory, relationship duration or action logistics according to the actual project.

## 5. Orthogonal axes

The four-axis compilation is **Skill synthesis**, not an externally established scholarly taxonomy. Investigation can have bounded openness or a required unique answer. Subjectivity does not imply polyphony; formal irregularity does not imply missing causal facts; atmosphere does not license opaque technical operations.

## 7. Template/context integration

Existing Project Poetics, Strategy, author Mission, Writer Mission, Character, Reader and Writer Reader Brief templates receive concise prompts within their existing structures. No parallel forms or universal numerical weights are required. Writer handoff uses ordinary language: current contribution, what should change/accumulate or stay stable, recurrence, focal/temporal operation, authorized closure and damaging generic optimization.

With an explicit `active_capabilities` declaration, the real compiler excludes disjoint `poetics-capability` entries, even with spare budget; making an inactive entry required blocks compilation. Legacy requests without that declaration keep their compatibility route. Authority/parent/scope hashes, strict visibility, expiry and task validation remain in force. Drafting qualification packets use a current Writer-safe brief; planning's full mature-volume material is not blindly copied into drafting. The fair-clue opening exposes observed scratches, rubber and access facts, not the later solution/sign-out evidence.

## 8. Readiness integration

Optional `draft_dependencies` evidence extends existing maturity evidence. A record supplies id, `required_for_draft`, reason and handling: `decided`, `preserve-open`, `not-applicable`, or `unresolved`. Required unresolved choices block. Required decisions cannot be laundered through openness or non-applicability. Decided/open handling needs substantive evidence references; preserved openness needs a compatibility boundary. These are dispositions, not narrative modes. Legacy evidence remains valid through its existing route.

Real readiness tests cover required unresolved culprit, required unresolved confessional voice, bounded authorial openness, non-applicable action-only obsession, required-openness laundering and empty boundaries. Existing approval, first-volume, context, maturity and validation gates remain operative. A structurally ready fixture is REVIEW_READY; tests do not counterfeit approval or publication readiness.

## 14. Remaining limitations

The deterministic backend validates explicit evidence/transport and known interventions; it cannot infer sufficient literary decisions from natural language. Legacy projects without draft-dependency declarations retain existing gates and are not retroactively semantically inspected. No model API was called and no independent judge responses were imported. Thus planning quality, chapter architecture quality, drafting, revision preservation and model-level metamorphic effects remain unqualified. Human controls and fingerprints are maintenance evidence only. Six-chapter trajectories are stage inputs, not completed generated novels or a longitudinal low-event literary campaign. Existing deterministic long-horizon tests cannot substitute for that campaign. Soak was not run.
