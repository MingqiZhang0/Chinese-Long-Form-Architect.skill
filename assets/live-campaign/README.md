# Live Campaign Evidence Assets

This directory contains the protocol registry and templates for real longitudinal creative campaigns.

No bundled file in this directory is evidence that a 50/100/200/300-chapter real campaign has already been completed.

`campaign-registry.json` intentionally begins with three planned tracks at **L0**. Advance a track only after a real project produces trace-grounded checkpoints under `references/live-campaign-longitudinal-evaluation.md`.

Do not copy synthetic long-horizon benchmark output here and relabel it as live evidence.

Each accepted checkpoint records project artifacts plus the active Skill/control-plane and campaign-harness hashes. Use `storyctl campaign trajectory` to inspect longitudinal growth and version changes without manufacturing a single composite score.

Passing memory/action probes must reference real project-relative evidence artifacts; the harness snapshots their hashes at capture time. Cold/hiatus/model-change checkpoints must also provide a structured resume probe and the exact recovery artifacts loaded.

Campaign maturity counts prospectively observed chapters after the registration anchor; the novel's absolute chapter number is not itself longitudinal evidence. `storyctl campaign status/trajectory/claim` also reports calendar-span and demonstrated memory-action horizon classes; these axes must never be collapsed into one score or inferred from one another.

Before a checkpoint can count, register the real creative session with `storyctl campaign session-start ...`; close it with `session-end` when practical. Session records are independently hashed, so distinct-session evidence is no longer inferred from arbitrary strings inside checkpoint JSON. `session-end` preserves completed, aborted, recovery-required, no-chapter, and other outcomes so longitudinal evidence does not silently erase failed or interrupted sessions.

Every probe declares a mode: `observational` for evidence arising naturally from the real writing workflow, `intervention` for an evaluator-injected challenge, or `recovery` for explicit resume/recovery testing. Report them separately. L4+ requires at least one passing observational action probe sourced after campaign registration; a campaign cannot establish naturalistic long-horizon usefulness using only evaluator-created quizzes.

Formal Chapter 1 handoff checks readiness before session-start; session evidence cannot authorize prose.
