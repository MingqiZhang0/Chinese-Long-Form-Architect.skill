# Chinese Narrative Evaluation Assets

This directory contains the **packaged, non-private** assets for `chinese-narrative-behavioral-evaluation.md`.

- `corpus-manifest.json` - seed-corpus version, counts, hash, rights/gold/holdout policies.
- `research-ledger.json` - subsystem view containing only canonical source IDs; bibliographic metadata/status live once in `assets/external-research-ledger.json`.
- `taxonomy.json` - open tag registry and allowed enum values for the v0.1 behavioral-evaluation contract.
- `contrast-family.schema.json` - machine-readable schema for one contrast family.
- `annotation.schema.json` - machine-readable schema for one blinded human annotation.
- `seed-families.jsonl` - provisional original-from-scratch seed families used as executable specification and smoke-test data.
- `annotation-template.jsonl` - example annotation records with no real annotator identity.

The seed suite is **not** a human-consensus benchmark. `private_holdout` items must never be stored in this directory or packaged inside the Skill.

Use `scripts/storyctl.py chinese-eval --help` for the deterministic tool surface.

Actual blind annotations must be collected against a packet generated by `build-blind`; `annotation-template.jsonl` demonstrates record shape only.
