# Project Poetics and Narrative Strategy

# Project Poetics

Organizing: 解释框架的支持与反证；身份连续性保持有界争议，不能靠巧合自动确认。
Reader success: 材料核验关闭；身份理论保留支持与反证，并有兼容边界。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 材料核验关闭；身份理论保留支持与反证，并有兼容边界。
Structural form: 按项目授权的六个贡献组织一卷，不强制事件升级。
Do not optimize: 禁止身份延续理论已经被证明为真；禁止所有巧合都证实了她的理论；禁止任何矛盾都可以随意解释。


# Mature first-volume architecture

1. 听到似曾相识的尾音；继承前章具体状态，语言与微动作留给起草。
2. 找到与记忆不符的转录；继承前章具体状态，语言与微动作留给起草。
3. 两份物证年代被核验；继承前章具体状态，语言与微动作留给起草。
4. 母亲记忆提供反证；继承前章具体状态，语言与微动作留给起草。
5. 预测下一处相似失败；继承前章具体状态，语言与微动作留给起草。
6. 核验工作完成但身份解释有界开放；继承前章具体状态，语言与微动作留给起草。
