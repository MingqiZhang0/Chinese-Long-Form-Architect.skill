# Project Poetics and Narrative Strategy

# Project Poetics

Organizing: 空间感知与关系距离；重复见面累积熟悉，亲近与理解可以反向运动。
Reader success: 熟悉加深而未来可行性下降；环境通过使用与位置进入关系。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 熟悉加深而未来可行性下降；环境通过使用与位置进入关系。
Structural form: 按项目授权的六个贡献组织一卷，不强制事件升级。
Do not optimize: 禁止突然发现谋杀线索；禁止双方其实都深爱着对方；禁止阴森诡异神秘恐怖。


# Mature first-volume architecture

1. 第一次交接只认车号；继承前章具体状态，语言与微动作留给起草。
2. 第二次记住雨衣的重量；继承前章具体状态，语言与微动作留给起草。
3. 第三次身体站位靠近；继承前章具体状态，语言与微动作留给起草。
4. 第四次路线变更没有说全；继承前章具体状态，语言与微动作留给起草。
5. 第五次熟悉的动作使误解加深；继承前章具体状态，语言与微动作留给起草。
6. 第六次交接留下可辨认的空位；继承前章具体状态，语言与微动作留给起草。
