# Project Poetics and Narrative Strategy

# Project Poetics

Organizing: 调查与局部严格闭合；系列熟悉感与关系累积，独立案件不必共享阴谋。
Reader success: 每案给出可回溯答案；关系累积，不发明共同幕后人。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 每案给出可回溯答案；关系累积，不发明共同幕后人。
Structural form: 三案局部闭合，系列累积。
Do not optimize: 禁止三案都是同一个幕后组织策划；禁止所有案件永远没有答案；禁止最后才凭空出现决定性证据。


# Mature first-volume architecture

1. 甲案观察编号并提出盗取或误抄；继承前章具体状态，语言与微动作留给起草。
2. 甲案排除盗取并闭合误抄；继承前章具体状态，语言与微动作留给起草。
3. 乙案比较签名和两次扣款；继承前章具体状态，语言与微动作留给起草。
4. 乙案闭合重复扣款并分配工作；继承前章具体状态，语言与微动作留给起草。
5. 丙案核对盖章与收件时间；继承前章具体状态，语言与微动作留给起草。
6. 丙案闭合且两人的桌面分工改变；继承前章具体状态，语言与微动作留给起草。
