# Writer-safe current contribution

仓储纠纷核验员郑雨与新同事顾环处理三个独立委托：甲箱号登记误抄，乙装卸费重复扣款，丙租赁工具归还日期争议。每案给出观察、两种当时合理假说、排除证据和唯一可回溯答案。


当前贡献：展开本项目可见观察与读者活动；只使用本章允许材料，不读取未来解释或后台候选。
# Project Poetics

Organizing: 调查与局部严格闭合；系列熟悉感与关系累积，独立案件不必共享阴谋。
Reader success: 每案给出可回溯答案；关系累积，不发明共同幕后人。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 每案给出可回溯答案；关系累积，不发明共同幕后人。
Structural form: 三案局部闭合，系列累积。
Do not optimize: 禁止三案都是同一个幕后组织策划；禁止所有案件永远没有答案；禁止最后才凭空出现决定性证据。

本章允许材料：甲案复写页末位六、登记纸九与相同压痕；乙案两个扣款相隔一分钟而只有一次签名和一次装卸记录；丙案次日盖章而门房在午夜前已经收件。三案均可在本章闭合，不能发明共同幕后人。
