# Project Poetics and Narrative Strategy

# Project Poetics

Organizing: 材料经验先于分类；有界假说与体验完成；异常不是欠缺资料的借口。
Reader success: 位置与操作清楚；成因保持两种文本可行路径，维护具有体验完成。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 位置与操作清楚；成因保持两种文本可行路径，维护具有体验完成。
Structural form: 按项目授权的六个贡献组织一卷，不强制事件升级。
Do not optimize: 禁止幕后原因已经全部解释清楚；禁止只有制造神秘才有价值；禁止她故意忘掉自己知道的原因。
