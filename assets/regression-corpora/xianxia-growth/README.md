# Xianxia-growth regression corpus

A progression-focused fantasy fixture. It stresses injuries, finite resources, travel, capability growth, and ordinary sect logistics without requiring a hidden-conspiracy architecture.

It is intentionally research-free: the fixture must prove that a Persistent project can use Runtime/context continuity without activating Reality Grounding or freshness machinery when no external factual dependency exists. Its Runtime includes an explicit regression-checkpoint import event so replayed current chapter/reader/thread state can be compared against Story State.
