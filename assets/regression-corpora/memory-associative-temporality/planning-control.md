# Project Poetics and Narrative Strategy

# Project Poetics

Organizing: 关联记忆、主观时间与社会观察；同一事实因讲述年龄而重新加权。
Reader success: 组织过去而非补齐年表；当下经过记忆返回后改变。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 组织过去而非补齐年表；当下经过记忆返回后改变。
Structural form: 按项目授权的六个贡献组织一卷，不强制事件升级。
Do not optimize: 禁止按年份依次讲完这些往事；禁止删掉这些与主线无关的记忆；禁止每段记忆都是未来案件的伏笔。


# Mature first-volume architecture

1. 现在门轴声触发剪刀记忆；继承前章具体状态，语言与微动作留给起草。
2. 从剪刀借还连到邻家称呼；继承前章具体状态，语言与微动作留给起草。
3. 青年抄账记忆改变赠送的理解；继承前章具体状态，语言与微动作留给起草。
4. 旧社交圈的沉默获得新的重量；继承前章具体状态，语言与微动作留给起草。
5. 同一剪刀事实再次回来而解释不同；继承前章具体状态，语言与微动作留给起草。
6. 回到三分钟后的排练室递纸；继承前章具体状态，语言与微动作留给起草。
