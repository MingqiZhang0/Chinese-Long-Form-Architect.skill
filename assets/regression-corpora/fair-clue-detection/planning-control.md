# Project Poetics and Narrative Strategy

# Project Poetics

- Status: approved-fixture
- Summary: A mystery where clue accessibility, knowledge asymmetry, inference fairness, and retrospective solvability are strict local commitments.
- Salience sources: clue, contradiction, inference, hypothesis revision
- Reader activities: infer, test hypotheses, remember evidence
- Progression modes: epistemic update, investigation
- Active capabilities: epistemic-puzzle, knowledge-topology
- Do not optimize: hide solution-critical facts unfairly, dilute clues into atmosphere-only detail


# Mature first-volume architecture

1. 林澈观察三道划痕、无撬痕和橡胶屑，先区分观察与推断
2. 公布门上橡胶挡片与两种可用搬运工具的尺寸：低推车与高提架；两者都暂可解释部分痕迹
3. 提前公布签领表、挡片磨损与底轮新补胶记录；值班员长钥匙记录不能证明只有他进过门
4. 对照最低划痕高度排除高提架，并依据签领表排除同时段另一人使用低推车
5. 重读已经公布的橡胶屑与底轮补胶：搬运员取走长钥匙，用低推车搬出箱子；所有决定性观察已在第2至3章可见
6. 唯一闭合未经授权的搬运；原有物理事实不变，读者可回溯重建，不借损坏监控掩藏证据
