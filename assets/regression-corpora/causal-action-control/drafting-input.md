# Project Poetics

Organizing: 因果行动与社会策略。
Reader activity: 跟踪选项、资源和可逆性。
Progression: 每个决定改变下一步可用选项；保持明确空间与操作顺序。
Mediation: 许峤的限定观察，不能读取对岸工人的思想。
Closure: 当前进水问题必须解决，资源损耗继承。
Do not optimize: 不把行动改成不相关的意识独白，不故意藏住执行步骤。
Inactive: 执念、关联记忆与开放本体。

许峤持有授权单；仅有一块电池，若转供报码器报警灯会熄灭；对岸开支渠，能够收到停支渠报码；水正在淹向控制线，闸柄可以手动操作；允许进水停止并把耗尽的电池记录为后果。
