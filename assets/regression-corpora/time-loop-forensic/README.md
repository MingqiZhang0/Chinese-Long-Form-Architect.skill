# Time-loop-forensic regression corpus

A branch- and knowledge-heavy fixture. It exists to stress semantic secret taint, counterfactual branches, role isolation, and high-assurance provenance without relying on literal secret-word leakage.

The fixture also carries one real project invariant, one semantic-revision impact report, and one approved prose-state reconciliation. These are intentionally minimal but non-empty so the Forensic profile is exercised by durable artifacts rather than placeholder directories.
Its Runtime also includes an explicit regression-checkpoint import event; replay must agree with the fixture Story State on current chapter, reader state, thread state, and loop iteration.
