# Project Poetics

Organizing: 程序解释与操作清晰；必要机制必须解释，不能被含混和氛围吞没。
Reader success: 操作顺序及必要机制清楚，不人为制造谜团。
Mediation: 限定观察与人物解释分开，不得偷换事实。
Closure: 操作顺序及必要机制清楚，不人为制造谜团。
Structural form: 按项目授权的六个贡献组织一卷，不强制事件升级。
Do not optimize: 禁止机制不能解释必须保持神秘；禁止先开清扫口再切断进气阀。
